# TECHLA (PVT) LTD - React Frontend

Next-Gen IT Solutions & High-Performance Computer Hardware Web Platform built with **React 18 + Vite + Tailwind CSS**.

---

## 🚀 How to Run:

```bash
# 1. Navigate into frontend folder
cd frontend

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

App will run at `http://localhost:3000`.
